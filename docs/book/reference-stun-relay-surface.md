# Reference: STUN Relay Surface

Read this page when the path is relay-oriented instead of plain binding.

Canonical entries covered here:

- `allocate`
- `refresh`

Current accepted aliases:

- `relay`
- `turn-allocate`
- `keepalive`
- `turn-refresh`

Operational split:

- `allocate` opens or extends relay-side allocation state
- `refresh` maintains or renews an existing relay allocation

Protocol package aliases also remain accepted:

- `stun-allocate`
- `stun_allocate`
- `stun-refresh`
- `stun_refresh`
