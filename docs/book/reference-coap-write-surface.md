# Reference: CoAP Write Surface

Read this page when the path mutates server-side resource state.

Canonical entries covered here:

- `post`
- `put`
- `delete`

Current accepted aliases:

- `write`
- `create`
- `update`
- `replace`
- `remove`
- `destroy`

Operational split:

- `post` usually creates or appends
- `put` usually replaces or updates
- `delete` removes a resource

Protocol package aliases also remain accepted:

- `coap-post`
- `coap_post`
- `coap-put`
- `coap_put`
- `coap-delete`
- `coap_delete`
