# Reference: GraphQL Mutation Surface

The `graphql/mutation` entry tracks write-style GraphQL traffic over HTTP POST.

Family hub: [GraphQL surface](docs/book/reference-graphql-surface.md)

## Debugging Focus

- Mutation candidate request path.
- HTTP response receipt.
- Process and route context for write failures.

## Typical Question

Use this entry when reads work but writes fail, time out, or trigger policy gates.
