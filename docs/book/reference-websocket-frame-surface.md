# Reference: WebSocket Frame Surface

The `websocket/frame` entry tracks text and binary frame opcodes after a WebSocket session has been established.

Family hub: [WebSocket surface](docs/book/reference-websocket-surface.md)

Canonical entry: `frame`

## Debugging Focus

- Local-to-remote text or binary frames.
- Remote-to-local text or binary frames.
- Directionality, route, and process context.

## Typical Question

Use this entry when the upgrade succeeds but the channel appears one-way, idle, or blocked after setup.
