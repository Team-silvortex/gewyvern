# Reference: Jaeger Trace Read Surface

The Jaeger trace-read surface tracks query API and dependency graph reads.

Family hub: [Jaeger surface](docs/book/reference-jaeger-surface.md)

Canonical entries: `query`, `dependencies`

## Debugging Focus

- Query service route selection.
- Trace search and trace detail response posture.
- Service dependency graph reads used to debug topology visibility.

## Typical Question

Use this surface when traces were ingested but search, trace detail, or service
dependency views do not show the expected data.
