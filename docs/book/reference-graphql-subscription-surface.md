# Reference: GraphQL Subscription Surface

The `graphql/subscription` entry tracks live GraphQL setup and follow-on frame traffic.

Family hub: [GraphQL surface](docs/book/reference-graphql-surface.md)

Canonical entry: `subscription`

## Debugging Focus

- HTTP upgrade or streaming setup.
- WebSocket text-frame traffic after setup.
- Directionality around live update delivery.

## Typical Question

Use this entry when normal HTTP GraphQL works but subscriptions never start, stop early, or only deliver in one direction.
