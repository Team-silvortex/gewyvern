# Reference: GraphQL Query Surface

The `graphql/query` entry tracks read-style GraphQL traffic over HTTP GET or POST.

Family hub: [GraphQL surface](docs/book/reference-graphql-surface.md)

Canonical entry: `query`

## Debugging Focus

- GET query-style request paths.
- POST query-style request paths.
- HTTP response receipt and route/process context.

## Typical Question

Use this entry when reads fail, stall, or route through the wrong proxy or gateway.
