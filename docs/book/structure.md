# Book Structure

The former six-part storyline has been replaced by domain modules and four
reading modes. This page remains as a stable link for older references.

- Choose a domain from the [documentation index](../index.md).
- Choose a reading mode from the [book index](index.md).
- Apply placement and ownership rules from the
  [documentation system](../documentation-system.md).

New book pages use exactly one prefix: `tutorial-`, `how-to-`, `reference-`,
or `explanation-`. They are linked from one owning domain module and, when
useful, one reading-mode index.
