# Reference: Loki Ruler Surface

The Loki ruler surface tracks API requests that inspect or mutate log-derived
recording and alerting rules.

Family hub: [Loki surface](docs/book/reference-loki-surface.md)

Canonical entries: `rules`

## Debugging Focus

- Ruler API route selection.
- Rule group reads and writes.
- Log-derived alerting posture.

## Typical Question

Use this surface when logs are queryable but log-derived alerts or recording
rules do not behave as expected.
