# v2.6.x Maintenance Line

The 2.6 series took direct UDP capture from the validation harness into the
Gewyvern CLI and installed Linux service. The source checkpoints run from
`a74f7254` (2.6.0) through `aba115a2` (2.6.9). These are source labels;
some binaries in the dated proofs still identify themselves as 2.5.0.

- [Live capture](../live-udp-capture.md) and [installed service recovery](../systemd-udp-recovery.md)
  cover explicit cgroup/port selection, IPv4/IPv6, loss accounting and a fresh
  run after the supervised process stops.
- [DNS](../production-dns-field.md) and [SNMP, NTP and STUN](../production-management-udp-field.md)
  use real services. They demonstrate specific UDP exchanges, not certification
  of every protocol package or general-purpose TCP capture.
- [Network fault checks](../production-udp-network.md) and
  [offload service checks](../production-udp-offload-service.md) distinguish
  missing observations from failed network delivery and incomplete groups from
  replayable evidence.

The [2.7 series](v2.7.x.md) continues that work at the point where a collector
publishes its last window and archives history.
