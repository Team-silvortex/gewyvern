# v0.13.x Minor Snapshot

This page records the role that `v0.13.x` played in the project's history.

`v0.13.x` was the first deliberate **convergence line**.

It was not trying to declare the project complete. It was trying to make the
project legible, bounded, and honestly reviewable before stronger release
claims.

## What v0.13.x Meant

The `v0.13.x` line meant:

- stop treating documentation, security boundaries, and surface wording as
  cleanup chores
- start treating them as release-shaping work
- reduce drift between runtime behavior, CLI behavior, and published docs
- make it possible to judge whether a later `0.14.x`-style maturity line was actually earned

It was the line where the project intentionally asked:

- what is the real contract candidate?
- what is still evolving?
- what should stop pretending to be temporary?

One example of that posture was the IR surface itself starting to grow a
recordable shape rather than staying only an ad hoc debug dump:

- focused IR inspection became a first-class compiler surface
- `program_model` and `reason_model` were treated as separate but comparable
  lowered views
- compact compare and archival snapshot structures became the kind of thing a
  release line could honestly point at

## What Already Looked Strong

Even in the `v0.13.x` phase, a lot already looked structurally mature:

- the runtime / compiler / report split
- the diagnosis spine
- the standalone CLI / `--serve` / API shape
- the external-engine boundary as additive rather than sovereign
- the ability to validate protocol shelves and packaged runtime behavior

## What Still Needed Convergence

The main work of `v0.13.x` was not "invent more surface".

It was:

- clarify the stable core
- narrow the machine-facing contract
- settle naming and compatibility edges
- document trust/exposure posture
- make pre-`1.0` release judgment evidence-based instead of aspirational

## Why This Snapshot Matters

Later minor maturity lines make more sense if this line is remembered clearly.

`v0.13.x` was the point where the project stopped being merely promising and
started becoming intentionally shape-complete.
